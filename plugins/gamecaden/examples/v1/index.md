# v1 填充样例

本目录是虚构项目与接口数据的合同样例。通过、接受和接入状态只用于演示分工，不代表真实游戏或用户判断。

项目入口见 [项目工作流](project/game-workflow/index.md)。I/O 请求使用 C:/ExampleGame 作为非执行示例路径，不应原样调用。

- Task T-001 内嵌 EV-001，并按自身小交付关闭。
- T-002 属于 E-001，依赖 T-001 的结果，而非简单依赖它的行政关闭。
- A-001 的 C-001 已指定给 A/B，示例 EV-002 只支持 A；B 仍未证实。
- D-001 将批量接受保存为事件；JSON 副本不另行保存，避免第二个可写源。

I/O 样例覆盖原生/旧格式读取、原 Task 更新、局部撤回、创建编号重试和提取中断。响应里的 written、分配编号及示意 after_revision 只演示协议，没有对样例项目执行对应写入；重放与中断恢复尚需后续真实工具验证。
